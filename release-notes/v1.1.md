# daft-doris 1.1

## Highlights

- Update the supported Daft baseline to 0.7.26.
- Verify the optional Ray read profile with Ray 2.59.0.
- Preserve the Daft NativeRunner write contract and fail before I/O when a Ray writer is selected.

## Compatibility

- Python 3.12 and 3.13.
- Daft 0.7.26 and PyArrow 19.0.1.
- The optional Ray profile resolves Ray 2.59.0 through Daft's Ray extra.
- Apache Doris 4.0.6 is the real-service integration target.

## Validation

- Unit and contract checks passed on the merged release source.
- The selected real Doris suite passed 24 cases with Python 3.12, Daft 0.7.26, and Ray 2.59.0.
- Python 3.13 minimum contract and installation checks passed.
- Wheel, source archive, and Twine checks passed.

## Scope

This release updates runtime compatibility and package metadata. It does not add a
new source or sink API, and Doris writes continue to use Daft's native runner.
